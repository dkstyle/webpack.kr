## CSS with no configuration

스타일 시트를 가져오면 나머지는 webpack이 처리합니다.

```js
import "./styles.css";
import * as button from "./button.module.css";
```

webpack은 `@import`와 `url()`을 리졸브하고, `*.module.css` 파일을 CSS Modules로 처리해 스코프를 지정하며, 청크마다 `.css` 파일을 추출합니다. `mode: "production"`에서는 CSS를 최소화하고(webpack 5.110.0 이상), [`browserslist` 타깃](/configuration/target/)을 지정하면 해당 브라우저에 필요한 벤더 접두사도 추가합니다. `module.rules`나 플러그인은 필요하지 않습니다.

## HTML pages with no plugin

페이지에서 스타일과 스크립트를 참조하세요.

**src/index.html**

```html
<link rel="stylesheet" href="./styles.css" />
<script type="module" src="./index.js"></script>
```

그런 다음 해당 페이지를 엔트리로 사용하세요.

**webpack.config.js**

```js
export default {
  entry: "./src/index.html",
};
```

webpack은 페이지가 참조하는 스크립트, 스타일 시트, 이미지를 번들링하고 해당 URL이 출력된 파일을 가리키도록 변경합니다. JavaScript 엔트리를 사용하는 프로젝트에서는 `output.html: true`로 페이지를 생성하고 스크립트와 스타일 시트를 연결할 수 있습니다. 제목, 파비콘, 하위 리소스 무결성(Subresource Integrity), CSP 등에 대해서는 [Native HTML](/guides/native-html/) 가이드를 참고하세요.

## What you can remove

다음 패키지는 내장 지원으로 대체되어 더 이상 사용이 권장되지 않습니다.

| 패키지                          | 대체 기능                                                                                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `css-loader`                    | 내장 CSS 파싱, `@import` / `url()` 리졸브 및 [CSS Modules](/guides/native-css/#css-modules)                                                       |
| `style-loader`                  | [`exportType: "style"`](/guides/native-css/#output-modes-exporttype)                                                                              |
| `mini-css-extract-plugin`       | 기본적으로 청크마다 `.css` 파일을 추출하는 내장 기능                                                                                              |
| `css-minimizer-webpack-plugin`  | 내장 [CSS 최소화](/guides/native-css/#minification) 및 [벤더 접두사](/guides/native-css/#vendor-prefixes) (5.110.0+)                              |
| `html-loader`                   | [JavaScript에서 `.html` 가져오기](/guides/native-html/#3-html-imported-from-javascript)                                                           |
| `html-webpack-plugin`           | [HTML 엔트리](/guides/native-html/#1-html-as-an-entry-point) 또는 [`output.html`](/guides/native-html/#2-a-generated-page-for-a-javascript-entry) |
| `html-minimizer-webpack-plugin` | 내장 [HTML 최소화](/guides/native-html/#minification) (5.110.0+)                                                                                  |

`sass-loader`, `less-loader`, `postcss-loader`, Pug 같은 전처리기와 템플릿 엔진은 내장 지원과 함께 계속 사용할 수 있습니다.

## Sass, Less, PostCSS and Tailwind

전처리기의 로더는 유지하고 그 뒤에서 실행되는 CSS 로더를 제거하세요. 규칙의 `type`이 전처리기의 출력을 webpack의 CSS 파이프라인으로 전달합니다.

```diff
 {
   test: /\.s[ac]ss$/i,
-  use: ["style-loader", "css-loader", "sass-loader"],
+  use: ["sass-loader"],
+  type: "css/auto",
 }
```

하나의 규칙으로 `layout.scss`(전역)와 `button.module.scss`(CSS Module)를 모두 처리합니다. `.css` 파일에 PostCSS와 Tailwind를 적용하는 방법과 `experiments.css: true`가 필요한 몇 가지 경우는 [Preprocessors, PostCSS and Tailwind](/guides/native-css/#preprocessors-postcss-and-tailwind)를 참고하세요.

## Existing projects keep working

기존 `css-loader`와 `html-loader` 설정은 계속 작동합니다. 기본적으로 webpack이 해당 규칙을 감지해 대응하는 내장 지원을 비활성화하므로 준비가 되었을 때 마이그레이션할 수 있습니다.

## Migrate an existing project

CSS는 [`@webpack/css-plugins-to-native-css`](https://app.codemod.com/registry/@webpack/css-plugins-to-native-css) codemod를 실행하세요.

```bash
npx codemod @webpack/css-plugins-to-native-css
```

HTML은 [`@webpack/html-plugins-to-native-html`](https://app.codemod.com/registry/@webpack/html-plugins-to-native-html) codemod를 실행하세요(webpack 5.112.0 이상).

```bash
npx codemod @webpack/html-plugins-to-native-html
```

직접 마이그레이션하려면 [Native CSS](/guides/native-css/#migration-guide)와 [Native HTML](/guides/native-html/#migrating-from-html-webpack-plugin) 가이드를 따르세요. `npx create-webpack-app`으로 생성한 새 프로젝트는 이미 내장 지원을 사용합니다.
