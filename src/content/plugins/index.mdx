Webpack에는 많은 플러그인 인터페이스가 있습니다. Webpack 자체에 있는 대부분의 기능은 플러그인 인터페이스를 사용합니다. 이런점이 webpack을 **유연하게** 만듭니다.

T> CSS와 HTML은 실험적인 내장 기능으로 지원하므로 [`MiniCssExtractPlugin`](/plugins/mini-css-extract-plugin)과 [`HtmlWebpackPlugin`](/plugins/html-webpack-plugin)을 이 목록에 포함하지 않습니다. 내장 기능이 지원하지 않는 항목을 위해 두 문서는 유지됩니다. [CSS](/guides/native-css/#whats-built-in) 및 [HTML](/guides/native-html/#whats-built-in)을 참고하세요.

| 이름                                                                            | 설명                                                                                     |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [`BannerPlugin`](/plugins/banner-plugin)                                        | 생성된 각 청크 상단에 banner를 추가합니다.                                               |
| [`ChunksWebpackPlugin`](/plugins/chunks-webpack-plugin/)                        | 번들 제공을 위해 엔트리 포인트와 청크 관계가 포함된 HTML 파일을 생성합니다.              |
| [`CompressionWebpackPlugin`](/plugins/compression-webpack-plugin)               | Content-Encoding으로 제공할 애셋의 압축 버전을 준비합니다.                               |
| [`ContextReplacementPlugin`](/plugins/context-replacement-plugin)               | `require` 표현식에서 추론된 context를 재정의합니다.                                      |
| [`CopyWebpackPlugin`](/plugins/copy-webpack-plugin)                             | 개별 파일 또는 전체 디렉터리를 빌드 디렉터리로 복사합니다.                               |
| [`DefinePlugin`](/plugins/define-plugin)                                        | 컴파일 시점에 설정되는 전역 상수를 사용할 수 있게 합니다.                                |
| [`DllPlugin`](/plugins/dll-plugin)                                              | 빌드 시간을 크게 줄이기 위해 번들을 분할합니다.                                          |
| [`EnvironmentPlugin`](/plugins/environment-plugin)                              | `process.env` key에 [`DefinePlugin`](/plugins/define-plugin)을 사용하는 shorthand입니다. |
| [`EslintWebpackPlugin`](/plugins/eslint-webpack-plugin)                         | webpack용 ESLint plugin입니다.                                                           |
| [`HotModuleReplacementPlugin`](/plugins/hot-module-replacement-plugin)          | Hot Module Replacement(HMR)를 활성화합니다.                                              |
| [`IgnorePlugin`](/plugins/ignore-plugin)                                        | 번들에서 특정 모듈을 제외합니다.                                                         |
| [`LimitChunkCountPlugin`](/plugins/limit-chunk-count-plugin)                    | 청킹을 제어할 수 있도록 청크 수의 최소/최대 제한을 설정합니다.                           |
| [`MergeDuplicateChunksPlugin`](/plugins/merge-duplicate-chunks-plugin)          | 동일한 모듈을 포함하는 청크를 병합합니다.                                                |
| [`MinChunkSizePlugin`](/plugins/min-chunk-size-plugin)                          | 청크 크기를 지정한 제한 이상으로 유지합니다.                                             |
| [`NoEmitOnErrorsPlugin`](/configuration/optimization/#optimizationemitonerrors) | 컴파일 오류가 있을 때 emit 단계를 건너뜁니다.                                            |
| [`NormalModuleReplacementPlugin`](/plugins/normal-module-replacement-plugin)    | 정규식과 일치하는 리소스를 교체합니다.                                                   |
| [`ProgressPlugin`](/plugins/progress-plugin)                                    | 컴파일 진행 상황을 보고합니다.                                                           |
| [`ProvidePlugin`](/plugins/provide-plugin)                                      | import 또는 require 없이 모듈을 사용할 수 있게 합니다.                                   |
| [`SourceMapDevToolPlugin`](/plugins/source-map-dev-tool-plugin)                 | source map을 더 세밀하게 제어할 수 있게 합니다.                                          |
| [`EvalSourceMapDevToolPlugin`](/plugins/eval-source-map-dev-tool-plugin)        | eval source map을 더 세밀하게 제어할 수 있게 합니다.                                     |
| [`SvgChunkWebpackPlugin`](/plugins/svg-chunk-webpack-plugin/)                   | 엔트리 포인트 의존성을 기반으로 SVGO가 최적화한 SVG sprite를 생성합니다.                 |
| [`MinimizerPlugin`](/plugins/minimizer-webpack-plugin/)                         | Terser 또는 다른 도구로 프로젝트의 JS/CSS/HTML/JSON 등을 minify합니다.                   |

더 많은 써드 파티 플러그인을 찾고 싶다면, [awesome-webpack](/awesome-webpack/#webpack-plugins)을 참고하세요.
